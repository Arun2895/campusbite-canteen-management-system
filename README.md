CampusBite is a modern, automated canteen management system designed to streamline ordering for students and staff. It replaces traditional manual queues with a real-time digital ordering system, featuring instant billing, menu updates and admin dashboards. CampusBite aims to save time, reduce manual errors, and enhance the overall canteen experience for both users and administrators.


---

## 📝 Key Features

| Feature | Description |
|---------|-------------|
| **Real-Time Ordering** | Place orders instantly through the web app without waiting in line. |
| **Automated Billing** | Generates e-bills automatically with counter number for easy pickup. |
| **Dynamic Menu** | Menu items and stock are updated in real-time to avoid unavailability. |
| **Admin Dashboard** | Admins can add/remove menu items, track orders, and monitor stock efficiently. |
| **Supabase Integration** | Secure backend with PostgreSQL and RLS to ensure safe multi-user access. |
| **SQL Scripts for Management** | Custom SQL scripts to handle database setup, RLS fixes and item additions. |

---

## 🛠️ Tech Stack

- **Frontend:**  
React + TypeScript  
Tailwind CSS  
- **Backend & Database:**  
Supabase (PostgreSQL)
SQL scripts for RLS, adding items, and setup  
- **Version Control:** Git + GitHub  
- **Environment Management:** `.env` for sensitive keys (ignored in Git)
